# Тестовый фреймворк на основе pytest и Selenium для автоматизации интернет-магазина Sportek

Автоматизированное тестирование интернет-магазина Sportek с использованием языка Python, Selenium WebDriver и pytest

## 🚀 Особенности

- **Page Object Model (POM)** — чистая и поддерживаемая структура тестов
- **Логирование** — подробные логи каждого шага для упрощения отладки
- **Генерация данных** — библиотека Faker для создания реалистичных тестовых пользователей

## 🛠️ Стек технологий

- **Python** 3.8+
- **Selenium WebDriver** — управление браузером
- **pytest** — фреймворк для тестирования
- **Faker** — генерация тестовых данных

## 📁 Структура проекта

Проект построен на паттерне Page Object Model, что обеспечивает разделение логики тестов и работы с элементами страниц

## 🐛 Найденные баги
В ходе автоматизированного тестирования были выявлены следующие дефекты:

- Некоторые названия товаров в каталоге и в корзине отличаются
- Цена в корзине может быть равна 0 или отличаться от цены в каталоге
- В фильтре "бренд" указаны некорректные названия товаров
- Итоговая стоимость заказа может отличаться от стоимости товара, даже если доставка бесплатная и нет никаких доп. услуг
- Неактивный чек-бокс "Страховка груза СДЭК"

## 🧪 Запуск тестов

### Установка и подготовка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/sportek-tests.git
   cd sportek-tests

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # для Linux/Mac
   .venv\Scripts\activate     # для Windows

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt

4. Запуск всех тестов:
   ```bash
   pytest

5. Запуск конкретного теста:
   ```bash
   pytest tests/test_authorization.py::test_buy_one_random_bike
